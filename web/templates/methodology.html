Methodology & data quality

Each displayed metric should be traceable to a column, a calculation, or a documented SQL query.

Data preparation rules

  1. Keep both original CSVs unchanged.
  2. Trim whitespace and normalize empty text to missing values.
  3. Convert expected numeric fields safely.
  4. Remove exact duplicate rows and repeated vehicle IDs, retaining the first record.
  5. Exclude records without a vehicle ID from the main fact table.
  6. Retain missing measurements as NULL; never silently turn them into zero.
  7. Create efficiency_kwh_per_100km as efficiency_wh_per_km / 10.

LIMITATIONS

Interpret the data responsibly

  • Confirm the Kaggle dataset name, author, license, and whether records are real, synthetic, or simulated.
  • model_year is vehicle model year; it must not be labelled as sales transaction year unless the source says so.
  • Aggregated annual_sales_units may double-count if the same model-level number is repeated across records.
  • Ratings and several numeric fields contain missing values; use non-null sample counts in charts where relevant.
  • Associations between battery capacity, range, price, or rating are not evidence of causation.
