# College requirement checklist

Mark an item complete only after the evidence exists. The scripts/templates in this repository are not evidence that manual Tableau tasks have been completed.

- [ ] Problem statement and project objectives reviewed.
- [ ] Kaggle source URL, author, date, license, and data provenance recorded.
- [ ] Original CSV files preserved under `data/raw/`.
- [ ] Data profile generated and reviewed.
- [ ] Cleaning pipeline run; cleaning report reviewed.
- [ ] Database selected and table row count verified.
- [ ] SQL queries executed and outputs checked.
- [ ] Tableau connected to SQL database or documented CSV fallback.
- [ ] At least 8 distinct Tableau worksheets authored and checked.
- [ ] Calculated fields created and manually verified.
- [ ] Interactive dashboard with useful filters and at least one action authored.
- [ ] Dashboard tested at different viewport sizes.
- [ ] Tableau Story scenes authored from verified findings.
- [ ] Performance tests completed; measured results logged.
- [ ] Tableau Dashboard published/hosted under permitted policy.
- [ ] Tableau Story published/hosted under permitted policy.
- [ ] Tableau view embed URLs configured in `.env` and Flask pages tested.
- [ ] Flask app, `/health`, and `/api/summary` tested.
- [ ] README, report, screenshots, data source notes, and demo script completed.
- [ ] GitHub repository checked for secrets, large files, and license compliance.
- [ ] Demo link and GitHub link added to the college portal.
